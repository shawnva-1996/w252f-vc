## Production defaults for original AI alternatives

1. Create **original** designs inspired by these high-level styles, rather than reproducing downloaded frames or source content pixel-for-pixel.
2. Prefer 3840x2160 (16:9) / 1920x1080 30 fps, 8–12 second seamless H.264 MP4 loops; export a clean PNG/JPEG still. Render a separate 3840x1280 LED wall variant if needed.
3. Keep center **safe for worship lyrics** (roughly center 70% width and 60% height), except the intentionally text-led JESUS design.
4. Soft movement, clean 1st/last frame match, no visible cuts, no camera shakes, no unrelated people or branding.
5. For Christmas presentations, optional project overlays and lyrics must remain editable in the presentation software; backgrounds should not burn in text.
6. Use originals or license-cleared generation outputs for the church; never redistribute licensed Sunday Screens originals in prompts, repositories, packages, or template archives.

## Reusable cross-model prompt wrapper

> Generate an ORIGINAL church Christmas worship background using the following visual specification. Keep the scene suitable behind high-contrast lyrics, free from text and logos unless explicitly specified. Use a restrained cinematic palette, refined textures, sophisticated lighting, and uncluttered depth. 16:9 composition with edge-to-edge coverage and central negative space. For video: gentle deliberate motion, 10 seconds, 30 fps, physically plausible lighting, loop without a visible seam. Do not copy an existing creator's asset; create a new interpretation.

**Negative prompt:** watermarks, copyrighted logos, irrelevant words, bad typography, excessive sharpness, flicker, rough video cuts, random zooms, blown-out white center, poor line consistency, disfigured human forms.
